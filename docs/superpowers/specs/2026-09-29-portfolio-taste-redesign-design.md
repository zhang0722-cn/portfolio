# 作品集精品化改版设计规格

- 日期：2026-09-29
- 状态：已确认设计，待规格审核
- 项目：zhang0722-cn/portfolio
- 技能：design-taste-frontend

## 1. 背景

当前作品集已经具备完整的个人信息、项目数据、技能和联系方式，但视觉层存在 AI 模板化痕迹：胶囊标签过多、重复双层圆角卡片、渐变文字、装饰光晕、等宽统计卡，以及各区块相似的淡入动画。作品图片没有成为页面的绝对主角。

本次改版采用“精品化保留”路线，不改变 URL、导航语义和项目内容，在现有暖灰与橙色品牌基础上重新建立排版、留白、作品展陈和动效秩序。

## 2. Design Read

Reading this as: solo designer portfolio for recruiters and design clients, with a restrained editorial brand language, leaning toward a targeted premium evolution of the existing off-white and orange system.

设置：

- DESIGN_VARIANCE: 7
- MOTION_INTENSITY: 6
- VISUAL_DENSITY: 3

## 3. 目标与非目标

### 目标

- 让真实作品图片成为最优先的视觉信息。
- 减少组件式装饰，建立编辑式排版和稳定的视觉节奏。
- 保留现有米白、暖灰和 `#EA580C` 橙色品牌识别。
- 保持招聘者快速扫描姓名、方向、作品、经历和联系方式的效率。
- 统一首页和项目详情页的视觉系统。
- 改善移动端排版、图片尺寸、键盘体验和减少动效支持。

### 非目标

- 不改变现有项目数据、联系方式、简历内容和主要文案。
- 不改变首页锚点、项目路由或 GitHub Pages 部署方式。
- 不引入新的 UI 框架或动画依赖。
- 不生成虚假作品图片，全部视觉素材使用仓库已有真实照片和项目图片。
- 不增加深色模式或其他品牌主题。

## 4. 视觉系统

### 颜色

- 主色保持 `#EA580C`，全站仅使用这一强调色。
- 背景层级：`#F1F0EC`、`#F7F6F2`。
- 主文字：`#181816`。
- 次级文字：`#696762`。
- 白色只用于图片、必要浮层和局部留白。
- 删除蓝色光晕、渐变文字、纯白大面积卡片和装饰性发光。

### 字体

- 大标题：`Space Grotesk`。
- 中文标题与正文：`Noto Sans SC`，系统回退到 `PingFang SC` 和 `Microsoft YaHei`。
- `StretchPro` 只用于年份、英文名和少量元信息。
- 不使用 `Inter`。
- 标题通过字号、字重、行高和留白建立层级，不使用大面积渐变。

### 布局

- 最大内容宽度：`1480px`。
- 区块垂直间距：桌面 `120px–180px`，移动端 `72px–96px`。
- 圆角系统：主要面板 `18px–22px`，小元素 `10px–12px`。
- 每个组件最多保留一层背景或边框，不再使用重复外壳。
- 信息优先通过细线、列、留白和字号区分，减少胶囊标签。

### 动效

- 使用 Framer Motion 完成进入、状态和轻微视差动画。
- 删除粒子画布、呼吸光斑、无限上下滚动提示。
- 图片使用 `clip-path` 或缩放揭示，文字使用短距离位移和淡入。
- 所有动画必须有层级、叙事、反馈或状态变化目的。
- 支持 `prefers-reduced-motion`。

## 5. 页面结构

### 导航栏

- 改为更薄的悬浮导航，滚动后使用暖白半透明背景。
- 左侧显示“张浩雷 / ZHANG HAOLEI”。
- 保留关于、项目、技能、联系。
- 右侧保留求职状态与下载简历。
- 桌面导航保持单行，高度不超过 80px。

### Hero

- 使用非对称双栏，删除粒子画布和光晕。
- 左侧：专业方向、姓名、简短介绍、查看项目和下载简历。
- 右侧：使用真实个人照片作为主视觉。
- `30+`、`20`、`80%` 数据移至项目或关于区块。
- Hero 最多保留四个文字元素：眉题或身份、标题、简介、CTA。
- 首屏内 CTA 可见，标题不超过两行。

### 关于我

- 个人照片移至 Hero，关于区块不再重复照片。
- 左侧用于城市、教育、求职状态等事实信息。
- 右侧用于简介和经历时间线。
- 时间线改成年份与内容两列，不使用圆点、竖线或重复卡片。
- 只修正明显标点和错别字，不重写个人经历内容。

### 精选项目

- 第一个项目采用大幅横向展示。
- 第二、第三个项目交替使用 `7:5` 与 `5:7` 布局。
- 项目标题、职责、年份和标签放在图片外部。
- 删除图片上的分类徽章、年份徽章和双层卡片边框。
- 桌面端保持明显不对称，移动端折叠为单列并保留大图。
- 项目详情路由与项目数据保持不变。

### 技能与证明

- 删除六个等宽卡片。
- 使用左侧标题、右侧能力列表的编辑式排版。
- 每项包含能力名称、一句说明和少量工具标签。
- 证书改为底部证据带，点击放大交互保留。
- 删除重复跑马灯，能力关键词并入技能区块。

### 联系区

- 删除居中的超大渐变标题。
- 改为左右分栏：左侧说明求职与合作意向，右侧列出邮箱、电话、城市和简历。
- 保留联系方式复制功能。
- 页脚简化为版权与联系入口。

### 项目详情页

- 保留现有路由、字段和用户内容。
- 继承新字体、间距、颜色、图片和正文排版。
- 强化返回入口和图片浏览，不改变 URL 结构。
